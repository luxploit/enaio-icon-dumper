# [luxploit](https://luxploit.net)/[enaio-icon-dumper](https://github.com/luxploit/enaio-icon-dumper)

A simple utility to dump icons from `enaio(R)` via the deprecated "AppConnector" API. This was last tested on `enaio(R)` v11.

> [!IMPORTANT]
> This utility is only for use with `enaio(R)` by `Optimal Systems` and has no official affilation or endorsement.
> Use at your own risk, bugs will not be fixed!
